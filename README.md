# 🚚 AI Logistics Shield: Resilient Supply Chain Optimizer

### 🏆 Google Solution Challenge 2026 - SDG 9 Entry

**Live Demo:** (https://logistics-app-332064394447.us-central1.run.app/)

## 🌟 The Problem
Modern logistics networks are brittle. A single grounded vessel or storm can cost the global economy billions. We built a solution that uses Generative AI to "think" like a logistics expert in real-time.

## 🛠️ The Google Cloud Stack
- **AI Engine:** Gemini 2.0 Flash (via Vertex AI SDK)
- **Backend:** Java Spring Boot
- **Infrastructure:** Google Cloud Run (Serverless)
- **Security:** GCP IAM Service Accounts (Zero-Trust)

## 🚀 How to Run Locally
1. Clone the repo.
2. Set your `GOOGLE_CLOUD_PROJECT` environment variable.
3. Run `./mvnw spring-boot:run`.
